# 簽／綜簽寫法與個人偏好（第二階段第 3 步）

寫簽前必讀。對應標竿案例的簽文段落寫法見 `local-examples.md`。

- **稿件型態與防テンプレート汙染**：原為「綜簽」就沿用綜簽，原為「簽」就用簽；**嚴禁照抄舊案的工程名稱或設施名稱（例如在 CCTV 案誤寫「高雄港過港隧道」）**；無實際誤植更正時，絕不照抄範例的會辦更正段落。
- **個人寫作五大偏好**：
  1. **金額一律用國字「億、萬」單位**：如 `5億1,890萬8,245元`、`3,677萬2,679元`，不寫純千分位長串阿拉伯數字。
  2. **去 AI 感四不原則**：【說明】各段開頭不加冒號小標題（如「一、案件背景：」）、【說明四】每筆財產在 `（一）（二）` 內一行連貫寫完不拆多行清單、不贅述細碎規費、擬辦簡潔扼要。
  3. **附件單獨標註與分割檔寫法**：每份文件後面**單獨寫明 `（附件○）`**；分割成多份的驗收證明書寫為 `（工程結算驗收證明書如附件2、附件3、附件4）`，**絕對不寫「第1至3份」**以免被誤會為附件 1～3。
  4. **主動交代「驗收總價 vs. 基金入帳額差異」與「未完工程沖後餘額去向」**：若驗收證明書總價含營業基金自辦項目，於【說明二】一開始就寫明全案驗收總價、營業基金自籌額與航港建設基金支應額；若未完工程沖銷後尚有他案共用餘額，於【說明三】寫明留待他案完工決算後處理。
  5. **紅字局部改稿模式**：若使用者已有草稿，**未要求修改的段落一字不動**，僅將修改或新增文字以 **$\textcolor{red}{\textbf{紅字}}$** 標示供直接替換。
