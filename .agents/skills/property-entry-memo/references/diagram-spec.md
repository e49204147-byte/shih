# 財產登帳三欄對照圖畫法規格（第二階段畫最後一號附件前必讀）

## 出圖基本規格

- 依據 `00_案件簽辦與審核總表.md` 【區塊四】的可編輯三欄文字底稿，以 Python `Pillow` 繪製白底簡約、高解析寬版（如 `2460 × 1250`，加寬卡片與畫布確保文字絕不壓框線、只用標準箭頭 `→` 避免方框亂碼）之 **`.jpg` 圖檔**，排在最後一號附件 `附件N`。
- 圖內標題固定為：**`「○○○工程」案財產登帳脈絡流程及經費核對對照圖`**；簽文【說明四】寫為：`全案財產登帳脈絡流程及經費核對對照圖如附件N`。
- 交付前最終核對：簽稿、`.jpg` 對照圖、財產單 PDF 及 `00_案件簽辦與審核總表.md` 的標的、日期、國字億萬金額和 `附件1~N` 編號 100% 一致。

標竿圖：[diagram-benchmark-S1S3.jpg](diagram-benchmark-S1S3.jpg)（原檔：`09_第七貨櫃中心案\01_S1-S3工程\1150817_S1~S3櫃場設施工程(簽辦中)\1151103_簽辦附件整理(1150068089)\附件13_S1-S3櫃場設施工程財產登帳_邏輯流向快速對照圖.jpg`）。畫圖前先打開標竿圖看版型。

## 這張圖是給誰看的
給**長官與會辦人員拿著圖逐項翻附件比對**用的。圖上每一個數字，都要讓人知道「去哪個附件找、跟誰比、比完得到什麼」。不是簽文摘要，不要照說明一、二、三的順序排。

## 三欄固定分工
| 欄 | 回答的問題 | 放什麼 |
| :--- | :--- | :--- |
| 左＝**對帳** | 錢對得上嗎？ | 驗收合格日、驗收總價、決算總額（含營業基金差額）；每個基金代號一段：`項次｜代號｜摘要`、`總撥付 − 已沖轉 ＝ 帳列餘額`、`★本次沖銷（沖後餘額／退還額）` |
| 中＝**依據** | 憑什麼可以這樣入？ | 上方一張依據卡：每列寫「日期＋文號＋（附件X）＋這份公文決定了什麼（一句話）」；下方每個拆分項目一張卡：金額、驗收日、屬性定性、適用法條或前案 |
| 右＝**入帳** | 最後入到哪張財產卡？ | 財產單每一列一張卡，欄位名稱跟財產單一樣：預算別、財產編號／序號、名稱／別名、取得／購置日、`原價 → 本次增（減）值 → 新價`、保管人 |

## 七條規則
1. **每張卡標題寫出處**：`【說明X】比對項目（附件Y）`，附件號要跟簽文一致。
2. **能寫成算式就寫成算式**，讓人拿計算機就能驗：例如 `1,065萬2,556元 ＋ 11萬5,809元 ＝ 1,076萬8,365元`。
3. **全案一條總勾稽式**放在中欄：`決算總額 ＝ Σ拆分項目 ＝ Σ財產入帳 ＝ Σ沖銷（＋退還）`。
4. **箭頭是卡對卡**：左欄的代號卡指向它支應的拆分項目，中欄第 k 張拆分卡指向右欄第 k 張財產卡，而且兩張卡要放在同一高度。多個代號支應同一筆財產時，箭頭匯到同一張卡。**多筆例外（動產超過 4～5 筆或採方案 A 多站建卡時）**：比照門哨 `附件09`／CCTV `附件11`，右欄改用**緊湊小卡**（標題＋2～3行欄位）或**彙整表格卡**呈現，中欄以匯流拆帳卡連向右欄整組財產即可，不必硬做一對一水平高度對齊。
5. **金額一律寫國字億萬**（`1億2,978萬3,305元`），不要寫 `129,783,305`。
6. **不放雜訊**：製單更正歷史、擬辦、附件總目錄、「示範版／未取得原檔／未逐列複核」這類工作備註都不要畫進圖。
7. **缺檔先問，不要畫**：未完工程明細表 Excel 沒拿到時，先停下來跟承辦人要檔，不要用撥付表的數字頂替。舊品另案報損可以放在右欄底部，用灰色小卡註明「非本次入帳，另案辦理」。

## 以風機案（1153314986）為例，三欄應該長這樣
- **左（對帳）**：驗收合格 115.2.24，發包結算 1,065萬2,556元（附件3）；決算 1,076萬8,365元（附件2）。項次727 `A0KHH115A210301`：撥付 1,065萬2,556元 → 沖銷 1,065萬2,556元，餘 0。項次685 `A0KHH114A210303`：撥付 11萬8,182元 → 沖銷 11萬5,809元，退還 2,373元（附件6、附件9 未完工程明細表）。
- **中（依據）**：113.9.11 航南字第1133315129號函，同意由基金支應、高港代辦修復；《國際（內）商港建設經費負擔原則》一之（一）規定公共基礎設施由基金負擔。拆分只有 1 項：修復工程併入既有風機財產增值 1,076萬8,365元 ＝ 1,065萬2,556元 ＋ 11萬5,809元。
- **右（入帳）**：財編 3080205-02-1 軸流式風扇（隧道通風設備，44台1組），原價 1億1,901萬4,940元 → 本次 ＋1,076萬8,365元 → 新價 1億2,978萬3,305元（附件7）。灰色小卡：舊風機 3 台帳面淨值約 193萬998元，另案報審計部減帳（附件8）。
