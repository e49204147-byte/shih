# `00_案件簽辦與審核總表.md` 五大區塊（第二階段第 2 步）

在案件整理資料夾內，統一產出唯一一份整合型 Markdown 總表 **`00_案件簽辦與審核總表.md`**（避免零碎 `.md` 弄亂資料夾），固定包含五大區塊：

- **【區塊一：應備文件正面表列與四大長官審核視角總表（Audit Checklist）】**：供承辦自我檢查及後續長官審核 Skill（`property-entry-audit`）直接讀取（包含：1. 基金公共基礎設施合規性、2. 產籍分類與折舊／先增後減／舊品審計法第58條報損、3. 驗收總價 vs. 決算入帳額 vs. 未完工程沖銷三方勾稽、4. 圖文與附件一致性）。
- **【區塊二：原始文件 OCR 數據與往返公文結構化表格】**：將掃描版之決算書、驗收證明書、款源分攤表、未完工程對帳表、財產單及歷次往返公文時間軸，完整轉為可搜尋、可複製的 Markdown 表格永久留存。
- **【區塊三：公文「簽／綜簽」正式定稿】**。
- **【區塊四：對照圖可編輯文字底稿（左／中／右三欄卡片文字）與 Mermaid 流程圖】**：讓承辦人未來想改圖上文字時，只需直接修改 `.md` 內的卡片文字即可重新出圖。
- **【區塊五：中心會議報告摘要（視需要）】**：交代先前會議核准項目、本次實際簽准入帳金額，以及尚有哪些核准項目（如高壓變電室地改）港務公司還未送件。
