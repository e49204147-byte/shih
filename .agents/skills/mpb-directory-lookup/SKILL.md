# 航港局通訊錄快速查詢技能 (MPB Directory Lookup Skill)

當使用者詢問航港局或各航務中心（北航、中航、南航、東航）同仁的電話、分機、職稱，或指定查詢某科室（如：南航港政科、北航監理科、航務組、港務組、祕書室等）人員名單時，請立即使用本技能。
## 回覆格式

查詢特定人員分機時，若最新可讀通訊錄只對應到一位人員，且分機確為四碼，最終回覆只輸出四個數字；不加姓名、單位、職稱、來源、耗時或其他說明。查證來源仍在內部完成。若有同名或多筆結果、分機不是四碼、資料缺漏或無法讀取，簡短說明並請使用者補足辨識線索，不猜號碼。使用者明確要求完整電話、職稱、名單或來源時，依其要求提供。

## 姓名打錯字時的同音查找

先按使用者所給姓名查最新通訊錄；完全相符且單位吻合時，依原回覆格式處理。查無完全相符時，不直接判定查無此人：從最新的 `*-flat.csv` 先看使用者指定單位（含其下屬科室）的姓名；沒有單位線索時先看同姓候選，再視需要擴大。比較姓名的國語讀音，納入同音不同字與常見選字誤植，例如「陳景會」可能是「陳景慧」；也要注意多音字，不能只憑字形相似或單一讀音認定。

找到候選時，逐一核對姓名、單位及分機。若原輸入與通訊錄姓名不完全相同，即使只有一位看似吻合，也先以「你是指○○○嗎？」請使用者確認；確認後才回覆四碼分機。多位同音或單位不符時列出必要的姓名與單位請使用者選擇；沒有可信候選就說明查無並請補充線索。不猜分機，不把舊版通訊錄或網路搜尋結果當成最新本機通訊錄。
## 1. 資料來源與自動快取機制

* **預設通訊錄資料夾**：`E:\下載\通訊錄`
* **自動更新與結構化總表**：
  本技能內建 PowerShell 查詢腳本 [`scripts/query_contacts.ps1`](file:///c:/2026aiagents/.agents/skills/mpb-directory-lookup/scripts/query_contacts.ps1)，執行時會：
  1. 自動尋找 `E:\下載\通訊錄` 中最新修改的 `.xlsx` 通訊錄檔案（如 `1150922-航港局通訊錄.xlsx`）。
  2. 若尚未轉出結構化總表（`*-flat.csv`），或發現有更新版的 `.xlsx` 檔案，腳本會**自動透過 Excel COM 將第一分頁（航港局）與第二分頁（航務中心）轉換為 UTF-8 CSV**，並將原本複雜的多欄並排表格自動攤平為「`Sheet, Dept, Title, Name, Ext`」五欄結構化總表。
  3. 若結構化總表已存在且為最新，腳本會直接讀取 `*-flat.csv`，在 **1 秒內**完成精準篩選與輸出。

## 2. 標準查詢指令（請優先執行此單一指令）

請勿手動解壓縮 `.xlsx` 或逐欄猜測座標，直接透過 `run_command` 執行以下單行指令即可一次取得結果：

### 依姓名或關鍵字查詢（例如：「北航 李宛麒」、「戴秀芬」）
```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8; powershell -NoProfile -ExecutionPolicy Bypass -File "c:\2026aiagents\.agents\skills\mpb-directory-lookup\scripts\query_contacts.ps1" -Keyword "李宛麒"
```

### 依科室單位查詢全體人員（例如：「南航港政科所有人」）
```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8; powershell -NoProfile -ExecutionPolicy Bypass -File "c:\2026aiagents\.agents\skills\mpb-directory-lookup\scripts\query_contacts.ps1" -Dept "南航港政"
```

### 依科室單位 + 職稱篩選（例如：「南航港政所有技士」）
```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8; powershell -NoProfile -ExecutionPolicy Bypass -File "c:\2026aiagents\.agents\skills\mpb-directory-lookup\scripts\query_contacts.ps1" -Dept "南航港政" -Title "技士"
```
*(提示：若查詢某科室之特定職稱，建議可直接使用 `-Dept "南航港政"` 撈出該科全部名單，如此可一併包含「約僱職代」而不會遺漏職務代理人！)*
