# 開工技能 (Startup Runbook)

本技能的本質是 **「讀」**，完全唯讀且無對外副作用。當使用者輸入以下觸發詞時，請執行此技能：
* **觸發詞**：`開工`、`我來了`、`上次做到哪`、`我們繼續`、`接下來呢`、`startup`

### 執行步驟：

1. **讀取 Obsidian 工作筆記與專案藍圖**：
   * 讀取專案根目錄的 [agents.md](file:///C:/2026aiagents/agents.md) 文件以瞭解整體專案狀態。
   * 讀取 [公務測試/handoff.md](file:///C:/2026aiagents/公務測試/handoff.md) 文件，載入上次收工時記錄的「上次做到哪」、「下一步/待辦事項」與重要提醒。

2. **檢查 Git 版本狀態**：
   * 在本機執行 `git status` 與 `git fetch` 指令，檢查本機與 GitHub 遠端倉庫的狀態差。
   * **注意**：僅獲取狀態（Fetch），**不要**主動執行 `git pull`，讓使用者有機會確認是否需要合併。

3. **摘要與開啟對話**：
   * 在對話中向使用者問候，並呈現：
     * 📋 **上次做到哪（進度摘要）**
     * 🎯 **本次工作的下一步 / 待辦清單**
     * 🌐 **Git 雲端同步狀態（是否有遠端更新）**
   * 詢問使用者今天要從哪個任務開始。
